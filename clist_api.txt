## 身份验证 Authentication

访问 API 需要 API 密钥，已认证用户可获取：`<API_KEY>`

- 也可通过网站会话进行非密钥访问（Non-key access）。
- OAuth 允许使用用户特定的筛选器，并在多个用户之间管理 API 请求限制。
- 使用方式：

```http
Request header:
Authorization: <AUTH_TOKEN>
```

或通过查询参数：

```
/?username=<USERNAME>&api_key=<API_KEY>
```

## 格式 Format

API 支持多种格式：`json`、`jsonp`、`yaml`、`xml`、`plist`。

- 在 URL 中指定：`/api/v4/json/...`
- 或通过 GET 查询参数指定：`?format=json`

## Atom 与 RSS

Atom 与 RSS 格式仅在 `/api/v4/contest/` 端点提供专门支持。

- 指定格式：`?format=atom` 或 `?format=rss`
- 默认设置：`?upcoming=true&format_time=true&start_time__during=1 day`
- 可通过 GET 查询或在用户偏好设置中自定义时区与时间格式。

## 限流 Throttle

- 标准请求限制：**每分钟 10 次**。
- 如需更高限额，请联系维护方说明需求。

## Account 账户

### GET `/api/v4/account/` — 获取账户列表

**响应 JSON 结构**

```json
{
  "meta": {
    "limit": "int",
    "next": "",
    "offset": "int",
    "previous": "",
    "total_count": "int"
  },
  "objects": {
    "account": [
      {
        "id": 0,
        "resource": "",
        "resource_id": 0,
        "handle": "",
        "name": "",
        "rating": 0,
        "n_contests": 0,
        "resource_rank": 0,
        "last_activity": "datetime"
      }
    ]
  }
}
```

**请求参数**

| 参数 | 位置 | 类型 | 说明 |
| --- | --- | --- | --- |
| `limit` | query | int | 每页显示的元素数量 |
| `offset` | query | int | 分页起始偏移量 |
| `total_count` | query | boolean | 布尔值，如 `True` |
| `id`、`id__in` | query | integer | 整数，如 `2673` |
| `resource_id`、`resource_id__in` | query | integer | 整数，如 `2673` |
| `resource`、`resource__regex`、`resource__iregex`、`resource__in` | query | string | 字符串，如 `"Hello World"` |
| `handle`、`handle__in`、`handle__startswith` | query | string | 字符串，如 `"Hello World"` |
| `rating`、`rating__gt`、`rating__lt`、`rating__gte`、`rating__lte`、`rating__isnull` | query | integer | 整数，如 `2673` |
| `resource_rank`、`resource_rank__gt`、`resource_rank__lt`、`resource_rank__gte`、`resource_rank__lte`、`resource_rank__isnull` | query | integer | 整数，如 `2673` |
| `last_activity`、`last_activity__gt`、`last_activity__lt`、`last_activity__gte`、`last_activity__lte`、`last_activity__week_day` | query | datetime | 日期时间字符串，如 `"2010-11-10T03:07:43"` |
| `order_by` | query | string | 按所选字段排序；默认升序，字段前加 `-` 为降序 |

**响应内容类型**：`application/json`

### GET `/api/v4/account/{id}/` — 按 ID 获取单个账户

| --- | --- | --- | --- |
